Política de Privacidad

Agente Himura · Última actualización: 29 de septiembre de 2026

Agente Himura es un asistente personal de uso privado, operado por su único titular. No es un servicio público, no tiene usuarios registrados y no ofrece cuentas a terceros.

Quién opera esta aplicación

La aplicación es operada de forma individual y privada por el titular de la cuenta agentehimura@gmail.com, que es a la vez el único usuario.

Qué datos se usan

La aplicación accede a la cuenta de Google del propio titular mediante OAuth 2.0, con estos permisos:

  • gmail.readonly — leer mensajes para clasificar notificaciones automáticas (avisos bancarios, vencimientos, alertas de servicios).
  • gmail.send — enviar avisos y resúmenes al propio titular.
No se accede a cuentas de terceros. La autorización se otorga exclusivamente sobre la casilla del propio titular, y puede revocarse en cualquier momento desde myaccount.google.com/permissions.

Dónde se guardan

Los datos procesados y las credenciales OAuth se almacenan de forma local y cifrada en un servidor privado bajo control exclusivo del titular. No se usan servicios de terceros para almacenarlos.

Con quién se comparten

Con nadie. No se venden, ceden, publican ni transfieren datos a terceros. No hay publicidad, analítica de terceros ni perfilado de usuarios.

Cuánto tiempo se conservan

Los datos se conservan mientras sean útiles para las tareas del asistente y se eliminan cuando dejan de serlo. Al revocarse el acceso OAuth, las credenciales quedan invalidadas de inmediato.

Seguridad

El acceso al servidor está restringido por clave. Las credenciales se guardan con permisos de lectura exclusivos del propietario del sistema. Toda la comunicación con las APIs de Google usa HTTPS.

Uso limitado de datos de Google

El uso de la información recibida desde las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.
